# Proyecto Final DW — SIGCA

Sistema Integral de Gestión de Citas y Atención.

## Avance 1

Estructura inicial de una aplicación con Vue, Express y MongoDB.

- `frontend/`: interfaz pública con Vue Router y Pinia.
- `backend/`: API REST y conexión a MongoDB mediante Mongoose.

Los módulos de servicios, contenido, pacientes, citas y finanzas se implementarán en siguientes avances.
